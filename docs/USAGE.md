## 1. 安装与启动

> 平台支持：核心功能（探测 / 选优 / 写入 / 回滚 / 托盘）Windows 与 macOS 通用；
> 自动保活为**应用内定时器**（不注册系统计划任务、无需管理员授权），
> 配合「托盘常驻 + 开机自启」长期运行。

### Windows

1. 下载 `GitHubCompass-Setup-x.y.z.exe` 安装包并运行；
2. 安装完成后从开始菜单或桌面快捷方式启动；
3. 首次启动将进入[首启向导](#2-首启向导)。

### macOS

下载 `.dmg` 镜像，将应用拖入「应用程序」文件夹后启动。

### 源码运行（开发者）

```bash
pnpm install
pnpm client:dev
```

## 2. 首启向导

向导共五步，可随时跳过；跳过后仍可在「设置 → 重新运行首启向导」中再次打开。

| 步骤 | 内容 | 说明 |
| --- | --- | --- |
| 1 欢迎 | 功能与边界说明 | 明确"仅优化本地 DNS 解析，无代理" |
| 2 环境检测 | 平台、hosts 路径、直接可写性 | 不可写时写入阶段会请求系统授权 |
| 3 拉取与探测 | 拉取候选池 → 本机逐 IP 实测 | 展示每域名最优 IP 与延迟 |
| 4 应用 | 授权写入 hosts / 只读导出 | 写入前自动备份 |
| 5 完成 | 结果确认 | 只读导出模式提供可复制的 hosts 片段 |

**只读导出（手动模式）**：不请求任何写权限，仅导出本地实测通过的 hosts 片段，
由用户自行追加到系统 hosts 文件末尾。适用于受限环境或希望完全手动控制的场景。

## 3. 主界面

### 3.1 仪表盘

- **状态横幅**：当前优化状态、种子数据版本与生成时间、上次写入时间、来源通道、本地探测通过数；
- **域名健康**：每个守护域名的当前 IP、TLS 校验标记与实测延迟条（绿 < 250ms，黄 < 450ms，红 ≥ 450ms）；
- **最近活动**：本机操作与自动巡检日志摘要；
- **立即更新**：将本地实测最优结果写入 hosts（写入前自动备份）。

### 3.2 探测详情

- 表格按域名分组展示全部候选 IP 的实测结果：连通性、TLS 证书校验、延迟、来源标记；
- **仅本地实测通过的 IP 可被选中写入**（hosts 为强制解析，写入不通的 IP 会阻断该域名的系统 DNS 可用路径）；
- 每域名单选一个 IP；「★ 本地最优」为默认推荐；
- 「按所选更新 hosts」按当前选择写入（写入前自动备份）。

### 3.3 备份回滚

- 每次写入前自动生成 hosts 全文备份，列表展示时间、触发来源与数据版本；
- 「预览 diff」对比备份时内容与当前 hosts（红删绿增）；
- 「↺ 回滚」需**两次点击**确认（防误触）；回滚执行前会再备份一次当前内容。

### 3.4 设置

| 分组 | 项目 | 说明 |
| --- | --- | --- |
| 自动保活 | 定时健康检查 + 劣化自动切换 | 应用内定时器，开启即用、无需系统授权；需保持托盘常驻 |
| 自动保活 | 检查间隔 | 5 / 10 / 15 / 30 分钟，改动即时生效 |
| 自动保活 | 保活状态 / 立即检查 | 展示下次/上次检查与结果；手动触发一轮完整检查 |
| 拉取通道 | 通道顺序开关 | 默认「raw 缓存 IP 直连 → 内置兜底池」；关闭即从顺序中移除 |
| 系统 | 开机自启 / 托盘常驻 / 语言 | 即时生效 |
| 高级 | 探测超时 / 并发 / 备份保留数 / 导出诊断日志 | 超时为单 IP TLS 握手等待上限 |

## 4. 托盘与开机自启

- 关闭窗口默认**最小化到托盘**（可在设置中关闭该行为）；托盘菜单提供「打开」与「退出」；
- 开启「开机自启」后，登录系统即自动启动并常驻托盘；
- 完全退出请通过托盘菜单「退出」。

## 5. 自动保活机制

开启后，应用内定时器按设定间隔静默执行一轮闭环检查（不注册系统计划任务）：

1. **健康检查**：对 hosts 标记块内全部条目做 TLS + HTTP 质量探测（失败自动复测一次，防单次抖动误判）；
2. **劣化切换**：不健康或传输过慢（首字节 > 1.5s）的域名，从候选池实测结果中选取更快者切换写入；候选不比当前更快时保持不动（防来回翻烧饼）；
3. **扩池兜底**：某域名候选池全部不可用时，本地多源 DNS 解析 + 官方 IP 段抽样 + 实测，动态补充候选；
4. **守护域自愈**：标记块中意外缺失的守护域名，自动从缓存候选 / 历史可用 IP 中探测恢复；
5. **冷却保护**：候选池暂无替代时进入 15 分钟冷却，避免网络受限窗口内空转重探（手动「立即检查」不受冷却限制）。

所有自动写入同样遵循「先备份、后写入、可回滚」。

> 说明：部分网络环境存在**时段性整体限速**，此时任何 IP 都会变慢，属网络侧行为；
> 窗口恢复后自动保活会在下一轮检查中自动切回优质 IP。

## 6. 常见问题与故障排查

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 写入失败 / 提示授权 | hosts 为系统保护文件 | 在 UAC（或管理员密码）弹窗中确认授权；拒绝则不会写入 |
| 探测全部失败且提示证书不受信 | 企业网 / 代理做了 SSL 检查 | 换可信网络重试；或按提示选择远程备选写入 |
| 写入后浏览器仍慢 | 浏览器 / 系统 DNS 缓存 | 重启浏览器；或等待自动保活下一轮切换 |
| 特定时段整体变慢 | 网络侧时段性限速 | 属网络行为，窗口恢复后自动切回；可用「立即检查」立即重试 |
| 想恢复原状 | — | 「备份回滚」选择写入前的备份回滚；或手动删除 hosts 中标记块 |
| 保活未生效 | 应用被退出（定时器随应用停止） | 重新打开 GitHubCompass 并开启开机自启 + 托盘常驻 |
| 诊断信息收集 | — | 设置 → 高级 → 导出诊断日志（仅本机操作记录，不含个人数据） |

## 7. 术语表

| 术语 | 含义 |
| --- | --- |
| 候选池 | 某域名的一组待验证官方 IP 列表（种子数据或本地扩池产出） |
| 探测 | 对单个 IP 做 TCP/TLS 握手与 HTTP 首字节质量的本地实测 |
| 选优 | 在同一域名的通过项中按传输质量（首字节耗时优先）选出写入者 |
| hosts 标记块 | hosts 文件中 `# GitHubCompass Host Start/End` 之间的内容，工具仅管理此区间 |
| 种子数据 | 随安装包内置的候选池快照（版本化，作为冷启动起点） |
| 扩池 | 候选池枯竭时，本地多源 DNS + 官方段抽样 + 实测动态补充候选 |
| 自动保活 | 应用内定时器周期性健康检查与自动切换的闭环机制 |
| 回滚 | 用某次写入前的备份恢复 hosts（回滚前再备份当前内容） |

## 8. 隐私与合规

- 全部探测、决策与写入均在**本机**完成；不上传、不遥测、不收集任何用户数据；
- 仅修改 hosts 标记块内容，不动其余系统配置；
- 不提供代理、不转发流量；仅将 GitHub 官方域名指向其官方真实 IP；
- 使用即代表知悉上述边界。详见仓库根目录免责声明与 [MIT 许可证](../LICENSE)。
